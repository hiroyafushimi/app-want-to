よくある質問

Q. API Key はどこで取得できますか？

OpenAI のウェブサイト (platform.openai.com) でアカウントを作成し、API Key を発行してください。

Q. AI 機能で送信されるデータは何ですか？

OCR で読み取ったテキストと選択したプロンプト（要約・翻訳等）が OpenAI のサーバーに送信されます。画像データは送信されません。初回利用時にアプリ内で同意確認を行います。

Q. 購入を復元するには？

設定画面のプランセクションから「アップグレード」をタップし、ペイウォール画面で「購入を復元」を選択してください。

Q. 無料プランの回数制限はいつリセットされますか？

毎日リセットされます。プレミアムプランでは回数無制限でご利用いただけます。

FAQ

Q. Where can I get an API Key?

Create an account on the OpenAI website (platform.openai.com) and generate an API Key.

Q. What data is sent when using AI features?

The text recognized by OCR and your selected prompt (summary, translation, etc.) are sent to OpenAI's servers. Image data is never sent. The app asks for your explicit consent before the first use.

Q. How do I restore my purchase?

Go to Settings, tap "Upgrade" in the plan section, then select "Restore Purchases" on the paywall screen.

Q. When does the free plan usage limit reset?

Limits reset daily. The Premium plan offers unlimited usage.
